## 制作一张可以在第二次访问后仍然存在的地图

室内差动驱动移动机器人两次通过记录同一堵墙。如果其车轮里程计在它们之间漂移，则扫描端点可以绘制相距几厘米的两堵墙。房间是否发生了变化，或者移动机器人是否错误地放置了一次扫描？这种模糊性将机器人的轨迹与其构建的地图联系起来。

| 问题 | 给定 | 估计 |
| --- | --- | --- |
| 里程计 | 来自车轮、图像或扫描对准的增量运动证据 | 短期相对运动和集成的局部位姿 |
| 本地化 | 参考地图和当前观测结果 | 在地图坐标中摆好位姿 |
| 使用已知位姿进行映射 | 观测结果及其传感器姿态 | 场景再现 |
| 同步定位与建图 (SLAM) | 观察和运动约束 | 相互一致的轨迹和场景模型，或者可以构建地图的轨迹 |

车轮里程计在观测之间很有用，可以支持平滑的局部估计。重访一个地方可以添加有关旧位姿和当前位姿的信息。实验室通过求解带或不带闭环的整个短轨迹来隔离该校正。它还展示了令人信服的错误关闭可以做什么。

## 沿着射线积累证据

要根据已知位姿构建 2D 占用网格，请选择每个单元的分辨率（以米为单位）和固定框架中的原点。对于轴对齐网格，栅格索引来自每个轴上的 `floor((coordinate - origin) / resolution)`。在光束采集时变换传感器原点和每个有效端点。遍历它们之间的栅格。简单的不透明命中模型在端点之前添加自由证据，在端点处占用证据，并单独留下端点后面的栅格。最大范围或丢失返回需要根据实际传感器合同进行解释。单个水平切片可能会错过头顶和低矮的障碍物。 [OctoMap 占用表示概述](https://octomap.github.io/) · [ROS LaserScan 消息](https://github.com/ros2/common_interfaces/blob/jazzy/sensor_msgs/msg/LaserScan.msg)

存储每个栅格的对数赔率 `L = ln(p / (1 - p))`。 `p = 0.5` 的先验给出 `L = 0`。在简单的单元证据模型下，为命中添加正对数似然比，为遍历添加负对数似然比。为了便于说明，添加 `+0.85` 表示命中，添加 `−0.40` 表示免费证据。两次命中和一次遍历产生 `L = 1.30` 或 `p = 1 / (1 + exp(−1.30)) ≈ 0.79`。这些增量是建模选择。相邻波束和重复扫描是相关的，因此独立的小区更新可能会夸大确定性。限制对数几率，以限制新观察后需要恢复多少证据。保留观察标记，以便将从未观察到的细胞与具有冲突证据的细胞区分开来。

网格分辨率将细节与记忆和姿态敏感性进行交换。 0.05 m 的单元无法挽救距真实位姿 0.10 m 的扫描。地标地图存储稀疏对象，并且当地标独特时可以有效地进行定位。网格可以直接进行自由空间查询，而位姿图可以保留重建该网格所需的历史扫描。根据下游查询以及轨迹是否还能改变来选择。

## 用闭环约束轨迹

```text
Time order:  [x0] -- m1 --> [x1] -- m2 --> [x2] -- ... --> [x6]
               |                                            |
               +---------- c: proposed revisit ------------+
               ^ fixed anchor               m_i: incremental measurements
```

节点在选定的采集时间处姿态。每条边都表示传感器在两个位姿之间测量到的相对变换。对于在同一坐标系中表达的位姿`X_i`和`X_j`，预测的相对变换是`inverse(X_i) X_j`。在局部平移和旋转坐标中表达与测量的相对位姿的差异，并用边缘不确定性对其进行加权。修复一个位姿或使用先验来消除将整个图形一起平移或旋转的自由度。这种原点的选择提供了参考，无需测量建筑物。优化器在受约束的位姿上重新分配残差。 [GTSAM PoseSLAM教程](https://gtsam.org/tutorials/intro.html#41-loop-closure-constraints)

数据关联决定哪些观测结果涉及同一地点或地标。外观相似的门和平行的走廊可能会产生看似合理但错误的候选解。搜索候选对象，验证相对几何形状，并拒绝由重叠太少或留下方向弱约束的几何形状支持的对齐。稳健的损失可以减少大残差的影响。如果错误的匹配受到很大的权重或没有竞争的匹配，则错误的匹配仍然可能使轨迹变形。一旦校正移动了历史位姿，就使用校正位姿处的相应扫描重建或更新地图。 SLAM Toolbox 记录了扫描匹配和位姿图工作流程，该工作流程使用与图形关联的扫描来构建地图。 [SLAM工具箱架构](https://github.com/SteveMacenski/slam_toolbox)

## 保留连续的局部框架

ROS REP 105 定义了树 `map → odom → base_link`。 `odom` 提供可漂移的连续本地参考。 `map` 提供长期参考，其中估计的机器人位姿可能会随着信息到达而跳跃。对 `odom → base_link` 使用一项权限，对 `map → odom` 使用一项权限。如果 `T_A_B` 采用 B 到 A 中的坐标，则将公共时间的校正计算为 `T_map_odom = T_map_base × inverse(T_odom_base)`。对于重访时的仅平移示例，+0.024 m 的地图位置和 +0.600 m 的里程计位置给出 -0.576 m 的校正。在带有偏航的 2D 中，请按顺序组合变换，因为旋转会改变平移的方向。比较回放中的两个帧轨迹，以捕获意外出现在本地里程计中的全局校正。 [ROS REP 105 框架和权限](https://github.com/ros-infrastructure/rep/blob/master/rep-0105.rst)

## 实验室：闭合往返轨迹

另存为 `sensing-slam.py` 并运行 `python sensing-slam.py`。合成移动机器人沿着一根轴以固定航向行驶和返回。所有位移均以该轴上的米为符号。起点固定在零。里程计的终点距起点+0.60 m，但实际终点为零。图实验室插入已验证的合成循环约束 `c = 0 m`，然后尝试与建议 `c = −0.80 m` 的功能进行错误关联。

求解修正后的增量 `d_i`。处罚总和为 `sum((d_i - m_i)² / sigma²) + (sum(d_i) - c)² / tau²`。这里 `sigma` 是每个里程计边缘的标准偏差，`tau` 是闭包的标准偏差。由于里程计权重相等，因此对每个 `d_i` 求导对每个边缘给出相同的校正。对导数方程求和，得到等于 `(sum(m_i) - c) × sigma² / (n × sigma² + tau²)` 的校正值，并从每个 `m_i` 中减去。这种特殊情况不需要数值求解器。

```python
from itertools import accumulate
from math import sqrt
from statistics import mean

truth = [0, 1, 2, 3, 2, 1, 0]
wheel = [1.10, 1.12, 1.08, -0.88, -0.90, -0.92]
sigma, tau = 0.12, 0.06  # assumed standard deviations in meters


def solve(closure):
    correction = 0.0
    if closure is not None:
        correction = ((sum(wheel) - closure) * sigma**2
                      / (len(wheel) * sigma**2 + tau**2))
    return list(accumulate((m - correction for m in wheel), initial=0.0))


for name, closure in [("odometry", None), ("true loop", 0.0), ("false loop", -0.8)]:
    poses = solve(closure)
    rmse = sqrt(mean((x - ref)**2 for x, ref in zip(poses, truth)))
    print(f"{name}: final={poses[-1]:+.3f} m, trajectory RMSE={rmse:.3f} m")
```

期望真循环将最终误差减少到 0.024 m，假循环使轨迹 RMSE 比里程计更差。打印每个校正后的位姿，以查看锚点移动后过去的每一步。对于所有三种情况，分数都使用相同的开始对齐参考和时间对应。该夹具说明了解决固定关联的后端。在完整堆栈中，分别根据已知的重访和相似的情况来衡量前端接受和拒绝的匹配。

在仿真器重放时，比较声明的对准中的时间戳匹配轨迹误差和固定间隔内的相对运动误差。还根据测量或模拟的几何形状对墙壁对齐和占用/自由一致性进行评分，并报告实际观察到的空间量。一个好的终点可以隐藏严重的早期漂移。报告重复路线上启用和禁用封闭的结果，并在封闭使地图变得更糟时检查高影响边缘。清晰的合并地图仍然可以将两个相同的走廊放在相同的坐标处。在考虑监督调试之前，请仔细检查相似的路线。

## 弘扬什么

- 使用位姿和光线证据来构建地图。保持占用空间、观察到的自由空间和未知空间的区别。
- 在信任位姿图的修正之前验证循环关联。测量轨迹和地图质量。
- 保持平滑的局部里程计并通过框架树公开全局校正。请参阅[帧和时钟](/zh/notes/ros2-frames-and-time/) 以了解带时间戳的转换查找。
