## 为什么要投影已知点？

假设探测器在立方体周围放置一个边界框，并且机器人知道立方体应该位于其基架中的位置。第一个诊断是将已知的 3D 点投影到图像中并将其与观察到的像素进行比较。这种廉价的检查可以在支付训练费用之前将不正确的相机位姿与模型错误区分开来。

相机对存在于三个维度中的点产生两个测量值。投影回答 **如果该点可见，哪个像素应该看到该点？**它没有回答 **这个像素在世界上的哪里？**没有其他测量或假设。此外，投影点不一定是可见的：尽管具有正深度，但它可能会被遮挡或位于可用图像之外。

```text
Point in scene   ── extrinsics ──▶  Point in camera frame
                                     │ divide by forward depth
                                     ▼
Pixel (u, v)     ◀── intrinsics ──  Normalized ray (X/Z, Y/Z)
```

本讲座的可观测结果是一些具有可预测方向的投影点，以及可用于提出下一个诊断的像素残差表。

## 基本原理

在 `Z` 朝前、`X` 朝右、`Y` 朝下的相机框架中，理想的针孔相机通过除以深度并应用其相机内参来投影相机前面的一个点 (`Z > 0`)：

```text
u = fx × (X / Z) + cx
v = fy × (Y / Z) + cy
```

`fx` 和 `fy` 是以像素表示的焦距。 `(cx, cy)` 是要点。本征描述了相机的成像几何形状；外部参数携带相机和另一个框架之间的坐标。镜头畸变不是这个理想模型的一部分。

通过想象相机前面一个单位的平面来导出除法。从原点穿过 `(X, Y, Z)` 的射线击中 `(X/Z, Y/Z, 1)` 处的平面。乘以焦距将归一化坐标缩放为像素；添加主点会将光轴置于图像中的测量位置。相机在 x 和 y 上可能有不同的焦距。在此约定中，像素 Y 处于下降状态：负相机 Y 移动到较小的像素行。

许多机器人使用+X朝前的机身框架。这与上面等式中的光学框架不同。如果在 world**中将位姿指定为 **camera，则它描述了世界中的相机轴和原点。投影世界点需要 **世界到相机 **变换，即该位姿的逆变换。在调试像素数学之前检查相机框架坐标。

## 算例

将`(X, Y, Z) = (0.1, −0.05, 1.0) m`放入相机取景框中，与`fx = fy = 600 px`和`(cx, cy) = (320, 240) px`一起。该点出现在 `(380, 210) px`：主点的右侧及其上方。

将所有三个坐标加倍会使两个比率保持不变。单个像素标识一条光线，而不是唯一的深度。

![侧视图显示在一个像素处穿过虚拟图像平面的同一视线上不同深度的两个点。](/assets/camera-projection.svg)

该图仅显示水平切片。同样的推理也适用于垂直方向：保持两个比率固定会留下相同的 2D 像素。

## 开发流程：制作一个小型投影预言机

将以下内容保存为 `project_points.py` 并使用 Python 3 运行它。它会在光轴、右侧、中心上方和更远的深度处检查模型。使该装置独立于整个相机管道。它适用于理想或校正的图像，而不是原始扭曲。

```python
from math import isclose


def project(point_camera, intrinsics):
    camera_x, camera_y, depth = point_camera
    focal_x, focal_y, center_x, center_y = intrinsics
    if depth <= 0:
        raise ValueError("point is not in front of the camera")
    return (
        focal_x * camera_x / depth + center_x,
        focal_y * camera_y / depth + center_y,
    )


intrinsics = (600, 600, 320, 240)
fixtures = [
    ((0.0, 0.0, 1.0), (320, 240)),
    ((0.1, 0.0, 1.0), (380, 240)),
    ((0.0, -0.05, 1.0), (320, 210)),
    ((0.1, -0.05, 2.0), (350, 225)),
]
for point, expected in fixtures:
    uv = project(point, intrinsics)
    assert all(isclose(actual, reference) for actual, reference in zip(uv, expected)), (point, uv)
    print(point, uv)
```

1. **实现最简单的模型。**三个坐标一致使用米。比率无单位；将毫米深度与米深度混合会破坏它们。
2. **验证边界。**正深度允许投影；显式图像边界告诉你它是否位于图像中。裁剪、调整大小或校正步骤会更改描述给定像素阵列的相机内参。要使用比例 `sx` 和 `sy` 调整大小，请缩放相应的焦距和主点坐标。对于裁剪，从主点减去裁剪的原点。
3. **T尝试故意错误。**在投影之前翻转 `camera_y` 的符号。光轴和水平情况仍然通过，但中心上方的点低于中心。单个中心点无法检测到此约定错误。
4. **使用多个场景点。**在多个深度处比较整个图像中观察到的减去预测的像素位置。将原始坐标和校正坐标分开。

| 说明性残差模式 | 用于检验的假设，而不是诊断 |
| --- | --- |
| 各处的像素偏移几乎相同 | 裁剪偏移或主点已更改。首先验证图像几何形状。 |
| 残差向边缘增长 | 检查比例尺、焦距变化或畸变模型；针对广泛的校准目标进行测试。 |
| 静止时正确，运动时错误 | 比较图像采集标记和选择用于投影的变换。 |
| 反复负深度 | 调谐校准前检查变换方向和光轴。 |

对于实际校准，请使用在一系列视图中采样的已知目标，拟合相机内参和失真，然后检查不同帧上的残差。较低的训练残差也可以来自更丰富的参数化，因此将验证视图集分开。 [OpenCV 相机模型](https://docs.opencv.org/4.x/d9/d0c/group__calib3d.html) 指定此处使用的约定。

## 弘扬什么

- 在检查像素数学之前检查外参和光轴。使用实际消耗的图像的匹配相机内参。
- 投影放弃了深度。要将像素反投影到 3D 点，请提供深度、使射线与已知几何体相交，或使用具有已知基线的第二个视图。
- 在更换检测器之前预测并检查残留图案。使用多个位置、深度和采集时间的点。
