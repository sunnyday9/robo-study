# Triage labels

The canonical role and GitHub label string are identical.

| Role and label | Meaning |
| --- | --- |
| `needs-triage` | A maintainer needs to evaluate the issue. |
| `needs-info` | More information is required before triage can proceed. |
| `ready-for-agent` | An agent can implement the specified work independently. |
| `ready-for-human` | The work requires human implementation. |
| `wontfix` | The issue will not be acted on. |
